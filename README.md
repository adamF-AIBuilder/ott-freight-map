# OTT Freight Map

Internal On Time Trucking lane / shipper directory. Open index.html (the app fetches data.json next to it).

- index.html — the app (map, views, key)
- data.json — the data, rebuilt from FarEye + Sage, US DOT FAF5, Census ZBP and the OTT quote engine
Rebuild: run make_v3.py. Don't edit these files by hand.
